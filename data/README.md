# data/

Raw datasets live here and are **git-ignored** (each exceeds GitHub's 100 MB per-file limit).

| File | Source | How to get it |
|---|---|---|
| `creditcard_ulb.csv` / `.arff` | ULB "Credit Card Fraud Detection" (video 2) | Downloaded automatically by `fraud_pipeline.data.load_ulb()` from its OpenML mirror and MD5-verified |
| `creditcard_2023.csv` (or repo root) | Kaggle `nelgiriyewithana/credit-card-fraud-detection-dataset-2023` | Download manually from Kaggle |
| `AIML Dataset.csv` (or similar) | Kaggle `amanalisiddiqui/fraud-detection-dataset` (video 3, PaySim, ~186 MB) | Download manually from Kaggle (free login); unzip into this folder |
